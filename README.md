# Tuppy releases

Installers and the update feed for **Tuppy**, a small companion that lives in the MacBook notch and shows your AI coding agent sessions.

This repository holds release files only. The source code is private.

- Each release has a disk image (`.dmg`), an installer package (`.pkg`), an update archive (`.zip`), `manifest.json` and its signature `manifest.json.sig`.
- Tuppy checks `releases/latest/download/manifest.json` for new versions, only if you turned update checks on in Settings. It sends nothing about you or your Mac.
